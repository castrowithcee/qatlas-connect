# Conversion sources

A conversion source tells a Merchant Center account where its conversion events come from. The Merchant API
(`conversions/v1`) knows two types, told apart by the prefix of the source ID:

| Type | ID | Meaning |
| --- | --- | --- |
| Merchant Center destination | `mcdn:ID` | conversion events of an online store sent by a Google tag directly to the account |
| Link to Google Analytics | `galk:ID` | conversion data of an existing Google Analytics property |

An account can have up to 200 sources. The tools take the `account` argument and are bound to the targets of the
connection like the other tools of the provider: the account is checked before any secret is read, and an account
that no target names is proven first.

| Tool | Effect | Does |
| --- | --- | --- |
| `google.merchant.conversion-sources.list` | read | lists the sources, `show_deleted` adds archived ones |
| `google.merchant.conversion-sources.get` | read | reads one source of either type |
| `google.merchant.conversion-sources.create` | create | creates a Merchant Center destination |
| `google.merchant.conversion-sources.update` | update | changes a Merchant Center destination |
| `google.merchant.conversion-sources.undelete` | update | restores an archived Merchant Center destination, tools list only |
| `google.merchant.conversion-sources.delete` | delete | archives or removes a source, tools list only |

## Reading

`list` and `get` return every documented member of `ConversionSource`: `name`, `state` (`ACTIVE`, `ARCHIVED`,
`PENDING`), `controller` (`MERCHANT`, `YOUTUBE_AFFILIATES`), `merchantCenterDestination` (`destination`,
`displayName`, `currencyCode`, `attributionSettings`) or `googleAnalyticsLink` (`property`, `propertyId`,
`attributionSettings`). `attributionSettings` holds `attributionModel`, `attributionLookbackWindowDays`, and the
list `conversionType` with `name` and `report`. A link to a Google Analytics property is shown, never written. The
member `expireTime` is not returned.

`list` takes `show_deleted`, `page_size` (1 to 200, Google sends 100 without it), and `cursor`. Google returns at
most 200 sources in total, so a list is complete after at most one batch of 200. Cursors are tied to the tool, the
account, `show_deleted`, the page size, and the targets.

Display names and the names of conversion types come from whoever runs the account and are untrusted content: a
name is cut at 300 characters, a list of conversion types at 100 entries, and a member that is not documented is
dropped.

## Writing

Only a Merchant Center destination can be written. No argument names a Google Analytics property, and the body
Qatlas sends has no member for a link, so no tool creates or changes one. An argument that is not listed, such as
`google_analytics_link` or `property_id`, ends the call before any secret is read.

`create` takes `display_name` (1 to 64 characters), `currency_code` (three capital letters, ISO 4217), and
`attribution_settings` with both `attribution_model` and `attribution_lookback_window_days`. All three are
required by the reference. `attribution_model` is one of `CROSS_CHANNEL_LAST_CLICK`, `ADS_PREFERRED_LAST_CLICK`,
`CROSS_CHANNEL_DATA_DRIVEN`, `CROSS_CHANNEL_FIRST_CLICK`, `CROSS_CHANNEL_LINEAR`,
`CROSS_CHANNEL_POSITION_BASED`, or `CROSS_CHANNEL_TIME_DECAY`, and the lookback window is 7, 30, or 40 days. The
list of conversion types is not an argument: Google creates a standard `purchase` type when it is empty. The
destination ID is generated by Google.

`update` is a `PATCH` with an `updateMask` that names each given member by its own path under
`merchantCenterDestination` (`displayName`, `currencyCode`, `attributionSettings.attributionModel`,
`attributionSettings.attributionLookbackWindowDays`). A member that is left out is kept, and at least one must be
given. `conversion_source` must be of the form `mcdn:ID`. Qatlas does not read the source first: the type prefix
of the ID keeps a source of another type out of reach, and a source Google refuses for another reason ends as the
error class of Google's answer.

The ID of a source goes into the request path only after it matches `galk:` or `mcdn:` followed by 1 to 64
letters, digits, underscores, or hyphens. The reference does not specify the characters after the colon, so
this form is narrower than what Google may issue.

Both writes need a confirmation and are in no profile. They are offered through the effects `create` and `update`
of a connection, or by naming them in its `tools` list. `create` is not idempotent: sending it again creates a
second source. Neither write is repeated, also not after `401`, `429`, or `5xx`. The result reports only that
Google accepted the request: Google builds or changes the source with a delay, so read it again after a while.
A new source is usually `PENDING` first.

## Removing and restoring

`delete` and `undelete` take `account` and `conversion_source`, both required, and send no body. They are offered
only where the `tools` list of a connection names them, need a confirmation, and are in no profile. Neither is
repeated, also not after `401`, `429`, or `5xx`. The result reports only that Google accepted the request.

`delete` takes a source of either type (`galk:` or `mcdn:`). A Merchant Center destination is archived and can be
restored for 30 days. A link to a Google Analytics property is removed immediately and cannot be restored: it can
only be created again, and no tool here creates one. The confirmation says so. Removing a source changes the
conversion data the account reports.

`undelete` re-enables an archived source and works only for a Merchant Center destination, so an ID that does not
start with `mcdn:` is refused before anything is sent. Its result carries `name` and `state` as Google reports them.

## Boundary

Checked against the discovery document of the conversions API v1 (revision 20261118): `list` returns 100 sources
by default and at most 200 in total, `displayName` is at most 64 characters, the lookback window is 7, 30, or 40,
and `merchantCenterDestination.destination`, `state`, `controller`, and `name` are output only. In the
reference `expireTime` is output only and not marked deprecated; it is still left out of the results.

The reference for `delete` states the 30 days for a Merchant Center destination and the
immediate removal of a Google Analytics link. The reference for `undelete` names no time limit for restoring: the
30 days come from `delete` only, and Google may refuse an undelete after that period. Both methods have an empty
request body, and `delete` answers with an empty object.

Not verified:

- No live call was made.
- Whether Google accepts the narrow paths of the update mask, or answers `400` for a member of a destination that
  it treats as immutable, for example the currency of a source that already receives events.
- What Google answers when a patch with a destination mask reaches a source of type `galk`. A source that Google
  rejects is reported by class and without Google's text.
- Whether the Merchant Center role of the credential allows writing conversion sources.

Deleting and restoring a source, and any write of a link to a Google Analytics property, are not offered.
